## 2. Plantilla de cada caso

**URL:** `/casos-de-exito/{nombre-del-cliente-o-proyecto}/`
**Título SEO:** {Cliente}: {resultado principal} · Caso de Éxito Verbo Taller
**Meta descripción:** Cómo ayudamos a {cliente} a {resultado}. {Servicio} por Verbo Taller, agencia de marketing en Santo Domingo.

Campos del caso (configurar con ACF o el plugin de tipos de contenido que se use):

| Campo | Ejemplo |
|---|---|
| Cliente | Nombre de la empresa (o "Empresa de tecnología" si no se puede nombrar) |
| Sector | Tecnología, salud, educación, consumo masivo… |
| Servicio relacionado | Enlace a la página del servicio |
| Categoría | Branding, Redes Sociales, Contenido, Publicidad, Estrategia, Web |
| Fecha | Mes y año |
| Resultado destacado | Una cifra o logro: "ROAS 4.5x", "3x engagement" |
| Imagen principal | 1200×800 px |
| Galería | Piezas, capturas, fotos o video |

Estructura del texto:

1. **El reto:** qué necesitaba el cliente y por qué.
2. **La solución:** qué hicimos (estrategia, piezas, canales).
3. **Los resultados:** cifras y logros concretos.
4. **Testimonio del cliente** (si lo hay).
5. **Botón:** "¿Quieres resultados así? Escríbenos" + enlace al servicio relacionado.
